这份工作表用于分析一个新模型或一项推理优化。每一格都应来自模型配置、固定版本源码、运行时日志、Profile 或压测结果。暂时没有证据时写“待核对”，不要用模型名称或经验数字补空白。

填写示例见[结业案例：从模型配置到优化判断](capstone.md)。

## 11. 最终结论

最终结论控制在一页内，并能回答：

```text
当前瓶颈在哪里，证据是什么？
方案直接改变了什么？
端到端收益是否达到预设目标？
哪些请求收益，哪些请求退化？
质量、容量和稳定性是否仍满足要求？
是否上线，若上线需要哪些保护和回退？
```

如果证据只能证明局部 Kernel 更快，结论就只写局部 Kernel 更快。不要把尚未测量的端到端收益补成推断。
